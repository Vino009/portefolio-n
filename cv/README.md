# CV Professionnel - ADINDJE DEO GRATIAS

## Fichiers

- `cv.html` - Fichier HTML du CV
- `cv-style.css` - Styles CSS du CV (charte graphique alignée avec le portfolio)

## Utilisation

### Visualisation à l'écran
Ouvrez simplement `cv.html` dans votre navigateur pour visualiser le CV.

### Export en PDF

#### Méthode 1 : Via le navigateur (Recommandé)
1. Ouvrez `cv.html` dans Chrome ou Edge
2. Appuyez sur `Ctrl + P` (ou `Cmd + P` sur Mac)
3. Sélectionnez "Enregistrer au format PDF" comme destination
4. Dans les paramètres d'impression :
   - Marges : Aucune
   - Options : Cochez "Graphiques d'arrière-plan"
   - Format : A4
5. Cliquez sur "Enregistrer"

#### Méthode 2 : Via un outil en ligne
- Utilisez un service comme HTML to PDF ou wkhtmltopdf
